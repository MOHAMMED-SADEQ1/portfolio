Overview

About This Project

This full-stack e-commerce website pairs a Laravel backend API with a Next.js storefront written in TypeScript to deliver an enterprise-grade shopping experience. Real-time inventory keeps stock levels accurate across every channel, while the Maysar payment gateway handles payments and refunds end-to-end.

Behind the storefront sits a powerful admin dashboard with business-intelligence reporting, advanced product and order management, and a promotions engine for coupons and campaigns. From catalog to checkout to analytics, every layer of the platform is designed to scale with the business.
