# Project Screenshots

Place your real screenshots here. Each project folder expects these files:

| File | Purpose |
| --- | --- |
| `cover.png` | Hero preview image on the project page |
| `gallery-1.png` | First gallery screenshot |
| `gallery-2.png` | Second gallery screenshot |
| `gallery-3.png` | Third gallery screenshot |

Until a file exists, the page shows a placeholder with the expected path. Add the image at the exact path and it appears automatically - no code changes needed.

The project pages (project-*.html) are standalone static HTML files.
To edit any page, edit its HTML file directly - no build step or extra tools required.

## Folders

- `hotel-pms/` - Cloud Hotel PMS / نظام حجوزات الفنادق السحابي
- `ecommerce/` - Full-Stack E-Commerce / متجر إلكتروني متكامل
- `laundry-pos/` - Laundry POS System / نظام مبيعات المغاسل
- `cloud-calendar/` - Synced Cloud Calendar / تطبيق تقويم ذكي
- `student-services/` - University Student Service System / نظام خدمة الطالب الجامعي
- `hotel-supervision/` - Hotel Internal Supervision System / نظام الإشراف الداخلي للفنادق
- `attendance/` - Employee Attendance System / نظام حضور وانصراف الموظفين
