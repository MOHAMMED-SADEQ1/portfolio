Overview

About This Project

The Employee Attendance System brings enterprise-grade attendance tracking to any organization. Employees clock in and out by scanning a personal barcode, and the record lands instantly in the system - built on a NestJS backend with a Flutter mobile app and a Flutter Desktop scanning station.

A React admin dashboard turns the raw scan data into meaningful insights: per-employee histories, department summaries, late and overtime analysis, and exportable reports. With a real-time data flow, management always sees an accurate picture of who is on site.
